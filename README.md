# Organize

**Sistema Inteligente de Organização e Produtividade Pessoal**

O **Organize** é um projeto desenvolvido em Python com o objetivo de facilitar a organização de tarefas, o planejamento de atividades e o acompanhamento da produtividade pessoal.

## 🎯 Objetivos

- Facilitar o planejamento e a organização das atividades diárias.
- Gerenciar tarefas, prazos, categorias e prioridades.
- Auxiliar na identificação das tarefas mais importantes e urgentes.
- Acompanhar o progresso das atividades e os resultados alcançados.
- Apresentar informações sobre a produtividade por meio de indicadores e estatísticas.
- Relembrar a sintaxe da linguagem Python
- Aplicar conceitos de Programação Orientada a Objetos (POO), persistência de dados e boas práticas de desenvolvimento.

## ⚙️ Funcionalidades

- [ ] Desenvolver a estrutura inicial do sistema.
- [ ] Implementar o cadastro e o gerenciamento de tarefas.
- [ ] Permitir a edição e a exclusão de tarefas.
- [ ] Organizar atividades por categorias e prioridades.
- [ ] Definir prazos para a conclusão das tarefas.
- [ ] Controlar o status das atividades: pendentes, em andamento e concluídas.
- [ ] Desenvolver um painel de acompanhamento da produtividade.
- [ ] Implementar um mecanismo de priorização inteligente de tarefas.
- [ ] Apresentar estatísticas sobre as atividades realizadas.
- [ ] Desenvolver uma interface gráfica intuitiva.
- [ ] Implementar o armazenamento persistente das informações.

> O projeto está em desenvolvimento. A lista de funcionalidades será atualizada conforme novas etapas forem concluídas.

## ✨ Diferenciais do projeto

O Organize busca ir além do registro convencional de tarefas, oferecendo recursos que auxiliem o usuário a planejar melhor seu tempo e suas responsabilidades.

- **Priorização inteligente:** identificar tarefas que merecem maior atenção considerando fatores como urgência, importância e prazo.
- **Visão geral da rotina:** apresentar um resumo das atividades pendentes, concluídas e atrasadas.
- **Acompanhamento da produtividade:** disponibilizar indicadores que permitam observar o progresso ao longo do tempo.
- **Organização centralizada:** reunir tarefas, categorias e prazos em um único ambiente.

Esses diferenciais serão implementados gradualmente, conforme a evolução do projeto.

## 📋 Gerenciamento de tarefas

Cada tarefa poderá reunir informações relevantes para sua organização e acompanhamento.

| Informação | Descrição |
|---|---|
| **Título** | Nome que identifica a tarefa. |
| **Descrição** | Detalhes e informações complementares. |
| **Categoria** | Classificação da atividade por tipo. |
| **Prioridade** | Nível de importância da tarefa. |
| **Prazo** | Data prevista para a conclusão. |
| **Status** | Situação atual da atividade. |
| **Data de criação** | Registro de quando a tarefa foi cadastrada. |

## 🛠️ Tecnologias e conceitos

- **Python** — linguagem utilizada no desenvolvimento da aplicação.
- **Programação Orientada a Objetos (POO)** — organização do sistema em classes, objetos e responsabilidades.
- **PySide6** — tecnologia prevista para a construção da interface gráfica.
- **SQLite** — banco de dados previsto para o armazenamento local das informações.
- **Git e GitHub** — versionamento e gerenciamento do código-fonte.
- **Testes de software** — verificação do funcionamento das regras e funcionalidades do sistema.

## 🏗️ Organização do projeto

O código será organizado em módulos e pacotes de acordo com suas responsabilidades, favorecendo a manutenção, a legibilidade e a evolução do sistema.

| Pacote | Responsabilidade |
|---|---|
| `model` | Representação das entidades do sistema, como tarefas e categorias. |
| `service` | Implementação das regras de negócio e operações do sistema. |
| `repository` | Gerenciamento da persistência e recuperação dos dados. |
| `ui` | Componentes responsáveis pela interface gráfica. |
| `database` | Configuração e acesso ao banco de dados. |
| `tests` | Testes das regras de negócio e dos componentes do sistema. |

A estrutura definitiva será estabelecida durante a implementação, de acordo com as necessidades da aplicação.

## 🚀 Objetivo de desenvolvimento

O Organize também tem como propósito servir como projeto de aprendizado e aplicação prática de conhecimentos em desenvolvimento de software, permitindo explorar desde a modelagem das entidades até a construção de uma interface gráfica e a integração com um banco de dados.
